## 🛩️ Lift

**Description:** A threejs glider sim. Basic controls and flight physics in place (physics need more work). Terrain needs work. Controls work best on mobile (desktop binary input sucks).

- 🚀 [https://lift-self.vercel.app/](https://lift-self.vercel.app/)
- 💻 [https://github.com/sfaber34/lift](https://github.com/sfaber34/lift)

## 🚘 Smash Fest

**Description:** Top down demolition derby game. Has basic multiplayer (partykit, no true lobbies). No win conditions yet, just a driving/party kit test. Note: there's a bug that makes desktop users drive much faster that mobile users (mobile speed is better).

- 🚀 [https://smash-fest-eight.vercel.app/](https://smash-fest-eight.vercel.app/)
- 💻 [https://github.com/sfaber34/smash-fest](https://github.com/sfaber34/smash-fest)
